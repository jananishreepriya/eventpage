# 🎉 Event Page – HTML & CSS Event Showcase Website

A clean and responsive event showcase website built during my self-learning journey. This project demonstrates my understanding of HTML5, CSS3, responsive web design, and structured webpage development. The website presents upcoming events, photo galleries, and contact information through an organized and visually appealing user interface.

🔗 **Live Demo:** https://eventpagesite.vercel.app/

This project was developed as part of my frontend development learning process and hands-on practice. I learned HTML and CSS concepts through YouTube tutorials and practical implementation, particularly from the **Error Makes Clever** channel.
